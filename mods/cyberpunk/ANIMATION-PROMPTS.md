# Cyberpunk — articulated gait masters

Each grid is painted from its own original body. `compose-animation.mjs` uses the vanilla frame registration library and freezes the torso so the turret mount never drifts.

### fabricator gait — `u.cyberpunk-fabricator.png`

refs: ../../../steel-tide-mods/mods/cyberpunk/art/sprites/u.cyberpunk-fabricator.png

```text
Create a grid of 4 animation frames arranged as exactly 2 columns by 2 rows, each cell exactly 1024×1024 pixels, total image 2048×2048 pixels. This is a WALK CYCLE sheet for the EXACT overhead robot in the reference. Read cells left-to-right, then top-to-bottom. The complete identical machine faces straight NORTH in every cell. Keep the central torso and its turret mounting ring pixel-identical, centred at exactly the same cell coordinates in all four cells. Only the articulated legs change pose. Pose 1: left front and opposite rear legs reach forward, the other legs push backward. Pose 2: legs pass under their hip joints. Pose 3: opposite diagonal pair reaches forward. Pose 4: passing pose reversed. The four poses loop smoothly. Show real joint rotation and foot displacement, not four copies and not the entire body moving. Keep all legs inside their cells with a broad clear margin. Preserve the reference's exact leg count, armour plates, graphite ceramic, bronze conduits, cyan optics and PURE MAGENTA team panels. If the reference has an empty turret ring, preserve it EMPTY in all frames. No turret or new gun added. Precise premium pixel art, dark #222034 outlines, hard edges. Orthographic directly overhead, never isometric, no sideways or diagonal pose, no foreshortening. Isolated on solid flat near-white #eeeeee matte, no checkerboard pattern. No labels, no text, no grid lines, no ground, no shadows, no borders. Every object equally scaled and exactly centred in its own equal square cell.
```
